# MLP

Recovered matched ocular-static MLP baseline folder.

Definition in the final manuscript:

- Flattens the eye sequence
- Encodes it with a multilayer perceptron
- Fuses it with the same 32-dimensional static physiological branch used by PhysioFormer-OS

Recovered final-paper metrics:

- Accuracy: `0.632`
- Macro-F1: `0.604`
- AUC (OvR): `0.818`
